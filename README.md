Spotify Clone Website:-
This is a front-end web application that replicates the user experience of Spotify. Users can browse, search, and listen to songs.
Features :
Browse and listen to a curated list of songs.
Users can upload their own songs (within file size limits) for others to enjoy.
Responsive design for mobile and desktop use.
Limitations :
Currently, due to GitHub’s file size restrictions (maximum 100 MB per file), large song files can't be hosted directly here. Instead, users can upload their songs within the app, and they’ll be streamed directly from the website once hosted elsewhere.
Tech Stack :
HTML, CSS, JavaScript
Responsive design (flexbox, media queries)
(Future) Integration with a backend service to handle large file storage (e.g., cloud hosting).
